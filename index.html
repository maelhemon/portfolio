Mes Missions

Mission 1 : Déploiement Infrastructure Réseau

Sept - Nov 2024

Mise en place d'une architecture réseau complète incluant configuration équipements, routage et sécurisation.

C1 - Administrer C4 - Sécuriser

📋 Contexte et Objectifs

Ouverture d'un nouveau site nécessitant infrastructure réseau. Enjeu : connectivité, sécurité et performance pour 50 utilisateurs.

  • Acteurs : équipe infra (3 pers.), responsable IT
  • Contraintes : budget limité, délai 2 mois, compatibilité
  • Objectif : infrastructure opérationnelle sécurisée

⚙️ Tâches et Évolution

  • S1-2 : Étude besoins, conception architecture
  • S3-5 : Config switchs/routeurs Cisco (VLANs, routage)
  • S6-7 : Pare-feu, filtrage, VPN site-to-site
  • S8 : Tests, documentation, formation
  • Autonomie progressive : supervisé puis autonome S5

🎓 Compétences & AC Mobilisés

  • C1 : Config avancée (VLANs, routage, protocols)
  • C4 : Sécurité, pare-feu, segmentation
  • AC : Configurer/dépanner services, garantir QoS

📎 Traces et Preuves

  • Schémas architecture (Packet Tracer)
  • Configs équipements anonymisées
  • Documentation technique
  • Rapports tests/validation

💭 Analyse Réflexive

Apprentissages : Maîtrise VLANs et routage inter-VLAN approfondie. Importance documentation.

Difficultés : Compatibilité versions IOS. Résolu via doc Cisco.

Évolution : Autonomie partielle → complète. Communication améliorée.

Niveau : Intermédiaire/Avancé - bonne maîtrise, résolution autonome.
